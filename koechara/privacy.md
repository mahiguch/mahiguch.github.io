# こえキャラ プライバシーポリシー

こえキャラ運営事務局（以下「当運営」といいます）は、アプリ「こえキャラ」（以下「本サービス」といいます）におけるユーザーの情報の取り扱いについて、以下のとおり定めます。

## 1. 取得する情報

- Google アカウントまたは Apple ID のプロフィール情報（表示名・アイコン等）
- メールアドレス（Apple でサインインする場合、Apple の「メールを非公開」機能による非公開リレーアドレスを含みます）
- 会話履歴
- 音声会話におけるマイクの音声（送信のみ）と、その文字起こしテキスト
- 音声会話の利用時間・回数（利用上限の管理とコスト監視のため）

## 2. 利用目的

取得した情報は、サービスの提供・改善、不正利用の防止のために利用します。

## 3. 外部送信

会話内容（テキストおよび音声）は、応答生成のため Firebase AI Logic を通じて生成AIに送信されます。

## 4. 保持期間

- 会話履歴（音声会話の文字起こしを含む）は、最終利用から1年経過後、順次削除されます。
- 音声データそのものは保存しません。
- 退会した場合、会話履歴およびアカウント情報は削除されます。

## 5. マイクの利用

マイクは音声会話の間のみ利用します。利用開始時に iOS の許可ダイアログで確認します。許可の設定は、iOS の「設定」アプリからいつでも変更できます。
